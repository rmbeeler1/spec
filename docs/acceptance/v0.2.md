# Acceptance: v0.2 "Import" (DRAFT, awaiting owner confirmation)

The verb for this release: a writer with a script trapped in Word, Final Draft, plain text, or a PDF gets it into Spec as correctly typed screenplay elements, fixes any misreads in bulk, and keeps writing.

Each box lists its proof when checked: a test name, a screenshot in `docs/evidence/`, or a manual check.

## Element classifier (packages/core)

- [x] Classifies plain text lines into screenplay elements using INT./EXT. patterns, ALL CAPS cues, transitions ending TO:, parentheticals, and blank-line context. Unit tests on hand-written tricky cases.
- [x] Uses layout hints when the source has them (centered, indented, bold) to raise confidence.
- [x] Every classified line carries a confidence value so the review pane can sort doubtful lines first.
- [x] Accuracy gate on the corpus: at least 95% of lines correctly typed on clean sources (text exported from Fountain), at least 85% on messy ones, measured against the known element types of the same script in Fountain.

## Importers (packages/core)

- [x] .txt and .md import through the classifier.
- [x] .docx import: paragraphs, alignment, indent and bold hints extracted from the document XML, then classified.
- [ ] .fdx import (already in core from v0.1) wired into the app's Open/Import flow.
- [ ] .pdf text-layer import, best effort, same classifier. Scanned PDFs without a text layer produce a clear error, not garbage.
- [x] Round-trip test per source format (txt, md, docx; fdx covered in v0.1; pdf pending): import, serialize to Fountain, reparse, element counts stable.

## App flow

- [ ] File > Import… accepts .fdx, .docx, .txt, .md, .pdf.
- [ ] Imports open in a review pane: a table of lines with their detected type and confidence, doubtful lines flagged, with bulk fixes (select several lines, set their type at once) before committing to the editor.
- [ ] Committing the review produces an untitled Fountain document in the editor; nothing is written to disk until the writer saves.
- [x] CLI gains the same importers (.docx/.txt/.md done, .pdf pending): `spec convert input.docx output.fountain` and the same for .txt/.md/.pdf.
