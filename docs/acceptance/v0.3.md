# Acceptance: v0.3 "Plan" (confirmed by the owner, Oct 12, 2026)

The verb for this release: a writer plans and reshapes a script without leaving the app. Scenes become cards you can reorder, beats live on a freeform board, the outline shows acts and sequences at a glance, cut material goes to a stash instead of the trash, and a pacing view makes the shape of the whole script visible.

Each box names its planned proof:
- **(live)** = exercised in the running app by an automated driver, screenshot in `docs/evidence/`.
- **(tests)** = covered by the automated suite (`pnpm test`).
- **(manual)** = needs a human hand or eye; the owner checks it.

The live driver's full 45-check log is `docs/evidence/v0.3-live-drive.txt` ("the drive" below). Automated suite: 218 tests green (`pnpm test`).

## Decisions (confirmed by the owner, Oct 12, 2026)

1. **Where planning data lives.** A sidecar file next to the script, `MyScript.spec.json` beside `MyScript.fountain`, not a required project folder. Opening a bare .fountain file keeps working exactly as today; the sidecar appears only once you use a planning feature. Card positions, colors, tags, tension values, and beat cards go in the sidecar keyed by stable element IDs. Script text never goes in it.
2. **Where stash text lives.** A `MyScript.stash.fountain` file next to the script, so cut material stays plain text and nothing is ever truly lost. The sidecar JSON holds only stash metadata (when cut, from where).
3. **Storylines.** In v0.3, storylines are tags with colors (defined in the sidecar, assignable to scenes); a dedicated storyline lane in the outline comes later if tagging proves useful.
