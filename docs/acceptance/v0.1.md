# Acceptance: v0.1 "Write"

A writer can draft a full script and send a correct PDF or FDX to anyone. Each box lists the proof: a test name (run `pnpm test`), a screenshot in `docs/evidence/`, or a manual check.

## Editor

- [x] Typing `int.`/`ext.` at a line start makes a scene heading on Enter, with the period and prefix normalized (`int house` becomes `INT. house`). Tests: `keyboard model > detects scene headings…`, `normalizes scene heading prefixes`. Screenshot: `v0.1-first-launch-hint-toolbar.png` (heading normalized in page and sidebar).
- [x] A short ALL CAPS line becomes a character cue on Enter; caps ending `TO:` becomes a transition. Test: `keyboard model > detects scene headings, transitions, cues and parentheticals`.
- [x] Enter follows the standard flow (scene>action, character>dialogue, dialogue>character, transition>scene). Test: `keyboard model > follows the standard flow on Enter`.
- [x] Tab and Shift+Tab cycle the element type; Cmd/Ctrl+1-6 set it directly. Test: `keyboard model > cycles types with Tab in both directions`. Manual: press Tab on any line.
- [x] The same character speaking again after action gets `(CONT'D)` automatically. Tests: `adds (CONT'D) when the same character speaks after action`, `does not add (CONT'D) across scene boundaries…`. Screenshot: `v0.1-auto-contd.png`.
- [x] Element toolbar above the page shows the six types with their shortcuts and sets the type on click. Screenshot: `v0.1-first-launch-hint-toolbar.png`.
- [x] Editor round-trips every corpus script through the Fountain model without loss. Test suite: `script <-> editor document round-trip on the corpus` (23 files).

## Discoverability

- [x] First launch shows a welcome hint; it stays dismissed afterwards and can be reopened from Help > Welcome Hint. Screenshot: `v0.1-first-launch-hint-toolbar.png`.
- [x] Help > Keyboard Shortcuts (Cmd/Ctrl+/) lists every shortcut. Screenshot: `v0.1-shortcuts-dialog.png`.

## Data safety

- [x] Saves are atomic (temp file then rename) and leave no temp files behind. Test: `atomicWrite > replaces existing files and leaves no temp files behind`.
- [x] Every save snapshots the previous version; snapshots list, restore, and prune at 25. Tests: `safeSave and snapshots` suite (4 tests).
- [x] Autosave runs 1.5s after a change once the file has a path. Manual: save a file, type, watch the status bar flip Editing… to Saved.
- [x] Closing with unsaved changes warns before discarding. Manual: type in a fresh window, press close.

## Pagination and export

- [x] Live page count and page-break markers in the editor, from the same engine as the PDF. Manual: open `test-corpus/fountain/spec-samples/Big Fish.fountain`, status bar reads 125 pages.
- [x] Big Fish paginates within the Final Draft parity window (124 +/- 4). Test: `Final Draft parity gate > Big Fish page count stays within the parity window`.
- [x] No orphaned cues, no headings at page bottom, (MORE)/(CONT'D) on dialogue breaks. Test suite: `pagination invariants on the corpus` (7 scripts).
- [x] PDF export opens, is styled, and matches the paginator's page count. Tests: `exportPdf` suite. 
- [x] FDX export round-trips through the FDX reader. Test suite: `FDX round-trip: write then read`.
- [x] Fountain export reparses identically. Test suite: `round-trip: parse -> serialize -> parse` (23 files).

## Navigation and modes

- [x] Scene navigator lists scenes in UPPERCASE, jumps on click, moves scenes up/down. Screenshot: `v0.1-first-launch-hint-toolbar.png` (sidebar). Manual: click a scene, use the arrows.
- [x] Title page editor writes Fountain title page keys. Manual: File > Title Page, fill Title, export PDF, check page one.
- [x] Find and replace with replace-all. Manual: Cmd/Ctrl+F.
- [x] Dark mode and focus mode. Screenshot: `v0.1-dark-focus.png`.
- [x] Templates: blank, feature, TV hour, TV half-hour. Manual: File > New from Template.
