# v0.1 "Write" report

## What was built

The first usable Spec: a Fountain-native screenplay editor for Windows, macOS and Linux. Core library (parser, pagination, FDX, PDF), the Electron editor shell, a CLI converter, and a release pipeline. After hands-on feedback, a discoverability pass was added: element toolbar with shortcuts, Help > Keyboard Shortcuts, a first-launch hint, scene heading normalization, and automatic (CONT'D).

The full checked acceptance list with evidence is in `docs/acceptance/v0.1.md`.

## What to click to try it

1. Install from https://github.com/rmbeeler1/spec/releases/tag/v0.1.0 (or `pnpm install && pnpm dev`).
2. Type `int. kitchen - day` and press Enter. Type a sentence of action, Enter, a NAME in caps, Enter, a line of dialogue. You just used the whole keyboard model.
3. Press Cmd/Ctrl+S to save; from then on everything autosaves and snapshots.
4. File > Export > PDF. Open it: correct Courier formatting, correct page breaks.
5. Help > Keyboard Shortcuts for the rest.

## Known gaps

- The editor is a continuous column with page-break markers, not discrete page cards. Mid-element page splits (a long speech) show no marker in the editor; the PDF is still correct.
- Scene reorder uses up/down buttons, not drag.
- Spellcheck is the OS one; no custom dictionary.
- Dual dialogue renders sequentially in print (side-by-side comes with v0.4 polish).
- macOS and Windows builds are unsigned: first launch needs right-click Open (Mac) or "Run anyway" (Windows).
- The Final Draft parity gate uses 124 +/- 4 pages for Big Fish from John August's published PDF; an exact FD export for the corpus is still wanted (see test-corpus/SOURCES.md follow-ups).

## Recommendation

Ship feedback rounds against real writing sessions while building v0.2 "Import" next: that is the wedge feature (messy Word scripts in, clean Fountain out) and its classifier work also hardens the parser. Acceptance draft: `docs/acceptance/v0.2.md`.
