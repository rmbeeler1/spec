# v0.3 "Plan" release report

Date: October 12, 2026. Owner-confirmed acceptance: `docs/acceptance/v0.3.md`.

## What was built

v0.3 turns Spec from an editor into a planning tool. Everything below works offline, keeps the Fountain file as the only home of script text, and survives crashes the same way the editor does (atomic writes everywhere).

- **Five views**, in the tab bar above the page or the View menu (Cmd+Alt+1 to 5): Write, Corkboard, Pacing, Beat Board, Outline.
- **Corkboard**: a card per scene. Click a body to edit the synopsis (it becomes a real `=` line in your Fountain). No synopsis? The first action line shows greyed, so your script reads on the board as-is. Drag a card onto another to reorder the actual script. Double-click opens the scene. The ⋯ menu sets color, tags and storylines.
- **Pacing**: scene cards in act lanes (from `#` sections) with page length in eighths, runtime, INT/EXT and time of day from the real paginator. Click the dots to set tension 1 to 5; the strip above draws the curve across the whole script, with gaps (not zeros) where you have not set one.
- **Beat Board**: freeform cards for ideas, draggable on a large canvas, linkable with flow lines. Never touches the script.
- **Outline**: acts, sequences and scenes in lanes; click to jump.
- **Stash**: select lines, press Cmd+Alt+X (or the pane button); cut material lands in `MyScript.stash.fountain`, plain text, restorable at the cursor. Cmd+Z after a stash move reverses both the script and the pane together.
- **Characters** tab in the sidebar: cue and scene counts, scene lists, and a filter that dims scenes a character is not in.
- **File handling**: planning data lives in `MyScript.spec.json` beside your script. File > Rename moves all three files together. If you rename a script outside the app, opening it finds the orphaned planning data and offers to re-attach it.
- Typing `# Act One` or `= synopsis` now creates real structure elements, and auto-shows structure if it was hidden.

## What to click to try it

1. Open your script. Press Cmd+Alt+2: your scenes are cards. Drag one somewhere wrong, press Cmd+Z.
2. Press Cmd+Alt+3, click tension dots on a few scenes, and watch the strip.
3. Select a paragraph you hate in Write view, press Cmd+Alt+X, then Cmd+Z, then Cmd+Shift+Z. Open the stash from the top right.
4. File > Rename your script and check the folder: all three files moved.

## How it was verified

- 218 automated tests across core, CLI and app (`pnpm test`), including sidecar round-trip and tolerant parsing, stash file round-trip, rename atomicity, orphan attach, character tallies on Big Fish, per-scene page stats against the paginator, and undo pairing.
- A 45-check live drive of the built app (corkboard drag and undo, tension gaps, beat links, outline jumps, character filter, stash undo/redo both directions, rename on disk, relaunch re-attachment, orphan prompt, structure auto-show), screenshots in `docs/evidence/v0.3-*.png`.
- Performance sanity on Big Fish (124 pages, 300+ scenes): see the perf lines in the drive log and the acceptance file; the owner should still confirm feel on their own script.

## Known gaps and honest notes

- Beat Board has no undo (planning data is outside the editor history); deleting a beat is confirmed by its edit dialog, but a mis-drag just has to be dragged back.
- Storylines are tags with colors, not an outline lane yet (per the confirmed decision; a lane comes if tagging proves useful).
- The corkboard reorders whole scenes only; it does not split or merge them.
- Scene detail edits on cards are synopsis-only by design; everything else is written in the editor.
- The tension strip points jump to the scene on click, but there is no hover tooltip beyond the native one.
