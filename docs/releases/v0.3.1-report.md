# v0.3.1 release report

Date: October 12, 2026. A fix release driven by the owner's first real import under the corpus agreement, plus one planning-safety feature. Tagged on the owner's explicit instruction in the same message that requested the fixes.

## What was fixed

All from one real file, `test-corpus/pdf/Untitled Zombie Shortfilm.pdf`, now a permanent regression gate:

1. Wrapped action lines merge into one flowing paragraph on import (all classifier formats), so imported action re-wraps at screenplay width.
2. Standalone page numbers ("2.", "Page 2") at page tops and bottoms are stripped before classification.
3. Final Draft style title pages route to the real title page; unfilled template placeholders like "(Name of Project)" are dropped. An untouched template yields a clean empty title page.
4. (MORE)/(CONT'D) page-break furniture is repaired: the split speech joins back into one, while legitimate mid-page (CONT'D) cues survive.
5. The review pane's type dropdown gains Shot.

## New: orphaned planning entries banner

When sidecar entries (colors, tags, tension) match no scene in the open script, a banner reports the count instead of leaving them silent. Review opens a dialog showing each entry with the heading it remembers; pick a scene and Attach (fields merge onto that scene), or Remove it on purpose. The banner also appears live, for example after stashing a colored scene.

## How it was verified

- 226 automated tests, including the zombie PDF gate (paragraph merge, no page numbers, no placeholders, re-joined speech with its (beat) intact, surviving legitimate (CONT'D) cues) and unit tests for orphan detection, re-attach merging, and removal.
- A 10-check live drive of the built app: re-imported the real PDF and exercised the banner end to end, including the re-attached entry landing in the on-disk sidecar. Log checks in the drive output; screenshots `docs/evidence/v0.3.1-*.png`.

## Known gaps

- The three manual feel-checks from v0.3 acceptance are still the owner's to confirm (corkboard feel, tension curve usefulness, keystroke feel on the real script).
- Page-number stripping only removes standalone number lines at a page's edges; a header like "Zombie Short - 2." would survive. Add a corpus file if one shows up.
