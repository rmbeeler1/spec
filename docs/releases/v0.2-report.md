# v0.2 "Import" report

## What was built

The wedge release: scripts trapped in other formats come into Spec as correctly typed screenplay elements.

- An element classifier in core with per-line confidence, driven by text patterns, blank-line context, and layout hints (centered, indent, bold). Accuracy gates run as tests: 95%+ on clean text, 85%+ on messy text, and a dedicated gate on a real-world messy Markdown screenplay (60/60 scene headings found).
- Importers for .docx (Word XML read directly), .pdf (text layer, with a clear "run OCR first" error for scans), .txt, and .md (syntax stripped, headings to sections, front matter to the title page). FDX and Fountain load directly.
- File > Import… and drag-and-drop onto the window, both landing in a review pane: summary with a sanity check, doubtful lines flagged and sorted first, bulk type fixes, one-click import when everything looks right.
- The CLI converts all of it: `spec convert script.docx script.fountain` (also .pdf/.txt/.md in, .fountain/.fdx/.pdf out).

The confirmed acceptance list with per-box live-vs-tests evidence is `docs/acceptance/v0.2.md`; screenshots in `docs/evidence/`.

## What to click to try it

1. Drag any Word, PDF, text, or Markdown script onto the Spec window (or File > Import…, Cmd/Ctrl+Shift+I).
2. Read the one-line summary at the top of the review pane. If it says the counts look normal and nothing alarming is flagged, press "Looks right — import".
3. If something is flagged: the doubtful lines are already sorted to the top. Click rows (shift-click for a range), pick the correct type, press Set type, then import.
4. The result is an untitled document; save it wherever you like and it becomes a normal autosaved Fountain file.

## Known gaps

- PDF import is text-layer only; scanned PDFs need OCR first (the app says so).
- The classifier does not try to detect dual dialogue or lyrics in imported text.
- Very large imports render the whole review table at once; a 4,000-line script is fine, a 40,000-line one would be sluggish.
- The native File > Import menu item is hand-tested only; the automated driver exercises the identical drag-and-drop path.
